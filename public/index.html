Welcome to austaltools documentation!¶

This documentation is currently being built up. Please do not expect it to be complete.

General¶

This module contains tools for use with Langrangian dispersion model AUSTAL (AUSbreitungsmodell nach TA Luft)

Installation:¶

Austaltools can be installed by

pip install austaltools

in principle. For more detailed instructions, see Installation

Command-line scripts:¶

The module contains the following scripts

austaltools

The main comand that provides all user-facing functionality.

Additional, more detailed user guides:

austaltools fill-timeseries

explains the Syntax of the cycle file cycle.yaml

austaltools heating

explains the Syntax of the cycle file heating.yaml

configure-austaltools

Download dataset for use with austaltools (or assemble them from the original sources)

austal-input

Convenience command for easy creation of AUSTAL input data

Provide input for AUSTAL (or AUSTAL2000)¶

austal-input¶

This is the most simple way to create input data for AUSTAL. For example:

austal-input 49.75 6.75 Kundelbach

will produce the files Kundelbach.gird and Kundelbach.akterm. It calls austal-weather and austal-terrain internally, selcting standard options (year 2000, default sources).

Its full command-line options are as the following:

Convenience command to produce AUSTAL input

usage: austal-input [-h] [--version] [--debug | -v] LAT LON NAME

Positional Arguments¶

LAT

Center position latitude

LON

Center position longitude

NAME

Stem for file names.

Named Arguments¶

--version

show program’s version number and exit

--debug

show informative output

-v, --verbose

show detailed output
