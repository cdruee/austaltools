austaltools
======

This module conatins tools for use with Langrangian dispersion model AUSLTA (AUSbreitungsmodell nach TA Luft)

Requirements:
-------------

    pip install numpy pandas meteolib

Installation:
-------------

    python3 setup.py install


Documentation: 
--------------
Preliminary documentation in German: Go to <https://meteo.uni-trier.de/austal-wissen/portfolio/roem-brennofen-allgemein/>
